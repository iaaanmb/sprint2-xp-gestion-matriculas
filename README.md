# Sprint 2 - Sistema de Gestion de Matriculas XP

Proyecto de curso de la asignatura Patrones y Metodologias de Construccion de Software PMD, de la Universidad Manuela Beltran UMB. Aplicacion web para la gestion de matriculas universitarias, desarrollada aplicando la metodologia agil eXtreme Programming XP.

## Equipo

Eyner Alexis Guarnizo Bonilla, Gabriel Santiago Guayana Gallegos, Ian Santiago Marquez Bustos.

## Stack

Backend Java con Spring Boot. Base de datos MySQL, base gestion_matriculas con 9 tablas InnoDB. Gestion agil con Trello y PlanITpoker.

## Historias de Usuario del Sprint 2

HU-001-1 Login, 5 puntos. HU-002-1 Inscribir materia, 13 puntos. HU-003-1 Consultar oferta de materias y pensum, 8 puntos. HU-004-1 Modificar o cancelar matricula, 8 puntos. HU-005-1 Asignar docente y salon a materia, 8 puntos. HU-006-1 Generar horario y reporte de matricula, 5 puntos. Total estimado del Sprint 2, 47 puntos de historia.

## Base de datos

El export de la base de datos, archivo gestion_matriculas.sql, se entrega junto con el informe de laboratorio y se restaura importandolo en MySQL.
